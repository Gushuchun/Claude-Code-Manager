# Security Policy

## Reporting a Vulnerability

ccm stores API keys on disk, so we take security seriously.

If you discover a security issue, please **do not** open a public issue.
Instead, report it privately:

- Use GitHub's private security advisories (the "Security" tab on the
  repository), or
- Email the maintainers directly.

Please include:

- A description of the vulnerability
- Steps to reproduce
- The impact you observed

We will acknowledge your report promptly and keep you updated on the fix.

## Supported Versions

Security fixes are applied to the latest release. Please keep ccm up to date.
